
# TaskFlow - Collaborative Sprint & Kanban Workspace

## Project Overview

TaskFlow is a responsive Kanban-based task management
application designed to organize tasks, manage priorities
and track project progress efficiently.

This project is being developed as part of the SkillMe
Full Stack Engineer Virtual Internship.

## Week 1 - Kanban Board Layout

The first milestone focuses on developing a static
Kanban board using HTML and CSS.

## Features

- Professional dashboard interface
- Three Kanban columns:
  - To Do
  - In Progress
  - Done
- Six sample task cards
- Colour-coded priority labels
- Task titles, descriptions and due dates
- Dashboard task statistics
- Add Task form
- Reusable task card components
- Responsive desktop and mobile layouts
- CSS Grid and Flexbox
- CSS variables for consistent styling
- Smooth hover effects

## Technologies Used

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Alternatively, use the Live Server extension.

No additional dependencies are required.
